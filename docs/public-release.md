# Public Release Notes

This repository is a curated source snapshot intended for technical review.

The following are intentionally excluded:

- model checkpoints and weights
- raw or processed training datasets
- evaluation caches
- generated PGN/result files
- `__pycache__` and interpreter artifacts
- local environment files
- API tokens, account credentials, or authentication configuration
- machine-specific paths

The Lichess adapter contains only engine-integration logic and does not embed authentication credentials.

The public snapshot contains the CNN and Transformer model implementations present in the selected source tree. Other experimental variants or generated artifacts are not represented here.
